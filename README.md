# HR Analytics Power BI Dashboard

## 📊 Project Overview

This project is an interactive HR Analytics Dashboard created using Microsoft Power BI.

The dashboard provides insights into employee workforce, attrition, job roles, income, overtime, age groups, experience, and gender distribution.

## 🎯 Objectives

- Analyze total employee workforce
- Monitor active employees and employee attrition
- Calculate attrition rate
- Analyze attrition across departments and job roles
- Understand employee age-group distribution
- Analyze overtime and attrition
- Compare average monthly income by job role
- Analyze employee experience
- Understand gender distribution

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning
- Data Analysis

## 📌 Key KPIs

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Experience

## 📈 Dashboard Visualizations

- Attrition by Department
- Attrition by Job Role
- Average Monthly Income by Job Role
- Attrition by Age Group
- Attrition by Overtime
- Attrition by Experience
- Gender Distribution
